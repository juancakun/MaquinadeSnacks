📌 Descripción

Este proyecto implementa un modelo sencillo de gestión de snacks utilizando principios de programación orientada a objetos. Cada snack cuenta con un identificador único, nombre y precio, y es almacenado en una lista centralizada que simula el inventario de la máquina.

El sistema permite:

Visualizar los snacks disponibles
Agregar nuevos productos al inventario
Gestionar datos de manera estructurada

🧠 Conceptos aplicados
Programación Orientada a Objetos (POO)
Encapsulamiento
Sobreescritura de métodos (toString, equals, hashCode)
Uso de colecciones (List, ArrayList)
Manejo de entrada de datos con Scanner
Inicialización estática
Identificadores autoincrementales

⚙️ Tecnologías
Java 21
Colecciones estándar de Java
Consola (CLI)

📂 Estructura del proyecto
Snack.java → Clase que representa un producto
Snacks.java → Gestión del inventario (lista de snacks)
MaquinaSnacks.java → Lógica principal e interacción con el usuario

🚀 Ejecución
Clona el repositorio
Compila el proyecto
Ejecuta la clase principal (MaquinaSnacks)
Interactúa con el menú en consola
